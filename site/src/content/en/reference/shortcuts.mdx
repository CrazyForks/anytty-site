# Default bindings and actions

This reference groups built-in public-client bindings by scene. Keys are case-sensitive: `r` and `R` differ. Use action IDs in configuration and client tutorials for operation guidance.

## Built-in versus recommended

| Action | Built-in | Installer-recommended |
| --- | --- | --- |
| History/copy | Ctrl+V, PageUp | Ctrl+Shift+C |
| Global clipboard history | No separate global key; H inside copy | Ctrl+Shift+H |
| Global system paste | P inside copy | Ctrl+Shift+V |
| Terminal picker | Ctrl+F | Ctrl+F |
| System mode | Ctrl+G | Ctrl+G |
| System prompt | : inside system | o inside system |
| Restart panel task | R inside panel | t inside panel |
| Kill panel task | X inside panel | k inside panel |
| Kill and close panel | No corresponding built-in binding | q inside panel |

The [complete recommended file](https://github.com/anytty/anytty/blob/main/tui/docs/tui-v3.recommended.yaml) may contain further differences. Installers preserve existing configuration; your footer and help show loaded bindings.

Unmodified Esc is reserved for returning and is omitted below. Omitted shortcuts preserve built-ins, actions-only changes presentation, and any explicit scene replaces the complete default scene catalog. See <DocLink locale="en" path="clients/tui/config/shortcuts">configuration</DocLink>.

Panel close, detach, kill and kill_and_close are distinct actions. Exact IDs below allow comparison with configuration.
