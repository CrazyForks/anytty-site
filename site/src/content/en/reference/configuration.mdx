# Configuration reference

This page centralizes values, validation ranges and supported environment overrides. Locate files with config paths, inspect final values with config show --effective, validate edits, then apply them at the relevant TUI or daemon startup.

Defaults below are runtime defaults, not the installer’s recommended profile. MiB is 1024² bytes; ms is milliseconds. Advanced templates are documented in the complete annotated file.

## daemon

| Field | Default | Range / values |
| --- | --- | --- |
| `daemon.output_buffer.capacity_bytes` | 33554432 | 65536–268435456 bytes |
| `daemon.output_buffer.resident_budget_bytes` | 536870912 | 65536–2147483648 bytes |
| `daemon.output_buffer.overflow` | block | block / drop |
| `daemon.history.max_size_mb` | 512 | 0–8388608 MiB; 0 = unlimited size |
| `daemon.history.max_age_days` | 0 | 0–36500 days; 0 = no age deletion |
| `daemon.history.compression` | zstd | zstd / s2 / none |
| `daemon.history.compression_level` | fast | fast / balanced / best |
| `daemon.resource_sampling.interval_ms` | 500 | 100–60000 ms |
| `daemon.resource_sampling.max_samples` | 512 | 512–65536 |

## Color fields

`tui.theme` fields `primary`, `secondary`, `foreground`, `background`, `muted`, `success`, `warning`, `danger` and `info` accept empty strings or `"#RRGGBB"`. So do `border.panel/active/inactive/muted` and `surface.chrome_bg/status_bg/overlay_bg/toast_bg`.

Empty colors use built-in, host-derived or calculated values. Currently system mode is not automatic OS theme synchronization, profile does not merge profiles, and clipboard max_items is not a sensitive-data erasure guarantee.

## Templates and action presentation

- Chrome workspace, tab, create-tab and pane-title templates are single-line display templates.
- `chrome.pane_glyphs` controls icons, decorations, owner and clipping indicators. Explicit empty decorations can hide content, unlike omission.
- `chrome.picker.endpoint_status` defines glyph/style per device state.
- `footer.templates` formats mode, key, action and summaries; `footer.modes` formats badges.
- `shortcuts.actions` changes presentation; any explicit scene replaces the default binding catalog.

See the [English annotated template](https://github.com/anytty/anytty/blob/main/tui/docs/tui-v3.example.en.yaml) and [recommended file](https://github.com/anytty/anytty/blob/main/tui/docs/tui-v3.recommended.yaml) for variables, style spans and actions. Templates do not store terminal/layout state.
