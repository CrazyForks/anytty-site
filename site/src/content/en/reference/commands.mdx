# CLI command reference

Expand commands by group to inspect arguments. These are public CLI help snapshots from this documentation review, without real devices or credentials. Compare with your installed command’s --help when versions differ.

## Conventions

ENDPOINT is a saved device ID; TARGET generally means ENDPOINT:TERMINAL_ID. Replace uppercase placeholders. Use --json only where supported and NDJSON for event streams.

Retain the returned target, inspect program exit_code after waiting, and remember that history search currently targets the local daemon. See <DocLink locale="en" path="clients/cli/overview">CLI introduction</DocLink> and <DocLink locale="en" path="clients/cli/automation">script results</DocLink>.

Common global options include --config, --socket, --log-file and --timeout. Subcommands can define their own timeout defaults. Run anytty for the TUI; use anytty update --check or anytty update for updates.
