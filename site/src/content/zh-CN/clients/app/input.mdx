# 触控、键盘与花瓣菜单

手机输入需要兼顾文字、控制键和终端程序自己的交互。App 提供软键盘、外接键盘和可配置花瓣菜单；先用无破坏性的输入验证操作习惯。

## 文字与控制键

点击终端输入区域调出键盘，在空闲 shell 输入 `pwd` 并回车，确认输入到正确设备。编辑器、交互式程序和普通 shell 对相同按键的解释不同；例如 Ctrl+C 可能中断当前任务，不是通用复制。

使用外接键盘时，留意系统或输入法占用的组合键。界面复制与发送终端控制键是不同操作。

## 配置花瓣菜单

进入设置中的终端 / 花瓣菜单相关项目，启用或关闭花瓣菜单，选择是否使用触觉反馈，再打开槽位编辑器配置常用动作。

建议先放置常用控制键和导航动作，再按实际工作补充。修改后回到一个测试终端逐项验证。重置布局会恢复默认槽位，执行前阅读确认提示。

## 键盘出现时的布局

终端设置提供 `Auto`、`Resize`、`Shift` 键盘模式。它们用于适应键盘占用的屏幕空间；根据实际设备检查提示符和光标是否仍可见。键盘布局适配与远端尺寸所有权是相关但不同的事情。

## 滚动和粘贴

滚动惯性可在终端设置中调整。复制输出后再粘贴到终端前，检查目标程序与文本里的换行。不要把多行命令误粘到编辑器、密码输入或正在运行的 REPL。
