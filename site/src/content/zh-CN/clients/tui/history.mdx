# 历史、复制与粘贴

实时屏幕只显示当前画面。需要回看输出、搜索错误或复制多行时，进入 AnyTTY 的历史与复制视图，避免把查看操作发送给正在运行的程序。

## 进入历史

内置配置使用 `Ctrl+V` 或 `PageUp`；安装器推荐配置使用 `Ctrl+Shift+C`。推荐配置还提供 `Ctrl+Shift+H` 剪贴板历史和 `Ctrl+Shift+V` 系统粘贴。宿主终端可能截获这些组合键，遇到冲突时先查看当前帮助，再调整宿主或 TUI 绑定。

## 搜索与复制

1. 进入历史视图，按 `/` 输入搜索内容，例如 `ERROR`。
2. 根据提示用 `Tab` 切换搜索模式，`n` / `N` 跳到后一个或前一个命中。
3. 移动光标到要复制的起点，按空格开始标记，再移动到终点。
4. 按 `y` 复制。用 `Esc` 退出当前选择或视图，回到实时终端。

内置历史导航支持方向键 / `hjkl`、`PageUp` / `PageDown`、`u` / `d` 半页、`g` 最早、`G` 最新。不要把“最新历史位置”和“程序当前已经就绪”混为一谈。

## 剪贴板历史与系统剪贴板

复制视图内置 `H` 打开剪贴板历史，`p` 粘贴最近条目，`P` 系统粘贴。剪贴板历史里 `Enter` 粘贴、`Ctrl+N` 新建、`Ctrl+E` 编辑、`Ctrl+X` 删除。

粘贴文本会送到当前终端程序；多行文本可能包含换行，粘贴前检查内容及焦点。系统剪贴板是否可用还取决于宿主终端和运行环境。

## 历史不是无限存档

保留大小与时间由 daemon 配置决定。较旧数据被清理或输出存在 gap 时，客户端无法凭空恢复。完整规则见<DocLink locale="zh-CN" path="concepts/history">实时画面与历史</DocLink>，保留设置见<DocLink locale="zh-CN" path="maintenance/config">daemon 配置</DocLink>。
