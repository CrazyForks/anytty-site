# 快速开始

这条路径先完成本机闭环：安装 CLI、启动当前用户的 daemon、创建一个可重新接管的终端。移动端和远程连接放在本机验证之后，排障会更简单。

## 1. 安装桌面端

macOS 或 Linux：

```sh
curl -fsSL https://raw.githubusercontent.com/anytty/anytty/main/install.sh | sh
```

Windows PowerShell：

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/anytty/anytty/main/install.ps1 -OutFile install.ps1
.\install.ps1
```

安装脚本会选择匹配的平台包并校验 SHA-256。若 shell 仍找不到 `anytty`，重新打开终端，再执行：

```sh
anytty --version
```

平台状态、手工安装和卸载说明见[安装、升级与卸载](../install-upgrade/)。

## 2. 启动 daemon

```sh
anytty daemon start
anytty daemon status
```

daemon 以当前系统用户运行，是 terminal、history、file 和访问授权的最终权威。若启动失败，先执行：

```sh
anytty daemon doctor
anytty daemon logs --lines 100
```

## 3. 打开 TUI

```sh
anytty
```

首次进入时可以在 TUI 中创建终端。也可以直接从 CLI 创建一个 shell 并附加：

```sh
anytty terminal create --name workspace --attach -- zsh
```

Windows 请把末尾命令换成实际安装的 shell，例如 `pwsh.exe`。退出 TUI 不会自动停止终端进程；再次运行 `anytty` 或 `anytty attach TERMINAL` 可以重新接管。

## 4. 检查终端状态

```sh
anytty terminal list
anytty terminal show workspace
```

终端名称便于识别，稳定 ID 才是跨重命名引用。长期任务可以添加 tags，并用 `events` 或 `wait` 观察生命周期。完整操作见[终端与桌面工作流](../terminals/)。

## 5. 配对移动端

先确认 daemon 已启动，然后在主机上创建一次性 claim：

```sh
anytty pair create
```

在 App 中扫描二维码或粘贴文本 claim。claim 默认有效期为 10 分钟且只能兑换一次；它不是永久凭据，不要发到聊天记录、issue 或截图中。配对完成后 App 会保存自己的客户端绑定凭据。

AnyTTY App 不会仅凭 Cloud 登录自动同步 daemon。每个客户端都需要显式配对，详见[移动端与平板端](../mobile/)和[配对、授权与设备管理](../pairing/)。

## 6. 连接另一台机器

根据网络和部署方式选择 route：

- 已经能 SSH 登录目标机时，优先配置 SSH endpoint。
- 同一可信网络内可使用 Direct，但只监听必要地址。
- 需要公网发现、P2P 协商和 Relay 兜底时，再启用 Cloud。
- Local 是当前机器的默认路径，不经过网络服务。

从[Endpoint 与连接方式](../connections/)继续配置，并用 `anytty endpoint test ID --route ROUTE` 单独验证每条路径。

## 完成检查

以下命令都成功后，本机基础环境就准备好了：

```sh
anytty --version
anytty config validate
anytty daemon status
anytty terminal list
anytty endpoint list
```
