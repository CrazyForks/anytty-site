# AnyTTY 产品文档总览

这里是 AnyTTY 产品文档的完整入口。正文围绕安装、连接、终端、文件和多端使用展开；协议实现与内部服务架构不属于这套产品文档。所有命令、默认值、平台状态和安全边界均以公开源码与当前 CLI 为依据。

## 建议阅读路径

- **第一次使用：** 产品介绍 -> 安装与升级 -> 快速开始 -> 终端与 TUI
- **运行 AI 编程任务：** AI Agent 工作流 -> 观察与接管 -> 历史回溯
- **需要手机接管终端：** 移动端 -> 配对与权限 -> 连接方式
- **需要访问远程机器：** Endpoint 与连接 -> Direct / SSH / Cloud -> 连接排障
- **准备长期运行：** 配置与运维 -> 安全与隐私 -> 故障排查
