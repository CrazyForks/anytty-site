# AnyTTY 文档

AnyTTY 让任务运行在你的电脑或服务器上，再从 TUI、手机 App 或 CLI 查看和操作。

## 第一步：把文档交给你的 Agent

把下面这段话发给你正在使用的 Agent，填上自己的问题。Agent 可以先读 GitHub 上的 `llm.txt`，再根据你的情况解释操作、查配置或协助排障。

<AgentGuideStart locale="zh-CN" />

例如：“帮我安装并打开第一个终端”“怎么修改 TUI 快捷键”“为什么手机连接不上电脑”。你可以在自己的 Agent 里继续追问，不必先读完整套文档。
