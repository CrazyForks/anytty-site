# 默认快捷键与动作

本页按 scene 汇总公开客户端源码中的内置绑定。大小写敏感，例如 `r` 与 `R` 不同。动作 ID 可用于配置；普通操作说明请先阅读对应客户端教程。

## 内置与推荐配置

| 操作 | 无显式 scene 时的内置键 | 安装器推荐配置 |
| --- | --- | --- |
| 历史 / 复制 | Ctrl+V、PageUp | Ctrl+Shift+C |
| 剪贴板历史全局入口 | 无独立全局绑定，可从 copy 内 H 进入 | Ctrl+Shift+H |
| 系统粘贴全局入口 | copy 内 P | Ctrl+Shift+V |
| 终端选择器 | Ctrl+F | Ctrl+F |
| 系统模式 | Ctrl+G | Ctrl+G |
| 系统 prompt | 系统模式内 : | 系统模式内 o |
| 面板重启 | 面板模式内 R | 面板模式内 t |
| 面板结束任务 | 面板模式内 X | 面板模式内 k |
| 结束并关闭面板 | 无对应内置绑定 | 面板模式内 q |

完整推荐配置可能还有其他差异，见[公开推荐文件](https://github.com/anytty/anytty/blob/main/tui/docs/tui-v3.recommended.yaml)。安装器不会覆盖已有配置，当前底部与帮助才反映你的实际绑定。

未修饰 Esc 是保留返回键，不列入下表。省略 shortcuts 保留内置绑定；actions-only 只改显示；任何显式 scene 都替换整套默认 scene catalog。详见<DocLink locale="zh-CN" path="clients/tui/config/shortcuts">快捷键配置</DocLink>。

面板 close、detach、kill、kill_and_close 是不同动作，不要根据显示标签猜测。下表直接保留动作 ID，便于与完整配置核对。
