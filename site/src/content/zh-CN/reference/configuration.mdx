# 配置字段参考

本页集中列出配置值、有效范围和受支持的环境覆盖。使用 `config paths` 找文件，使用 `config show --effective` 看最终值；修改后 `config validate`，再按 TUI / daemon 各自的生效时机应用。

默认值与安装器提供的推荐配置不同。下表的默认值指运行时内置默认值，范围指允许值；byte 是字节，MiB 是 1024² 字节，ms 是毫秒。未列出的高级模板可在完整注释文件中逐项查阅。

## daemon

| 字段 | 默认值 | 范围 / 可选值 |
| --- | --- | --- |
| `daemon.output_buffer.capacity_bytes` | 33554432 | 65536–268435456 字节 |
| `daemon.output_buffer.resident_budget_bytes` | 536870912 | 65536–2147483648 字节 |
| `daemon.output_buffer.overflow` | block | block / drop |
| `daemon.history.max_size_mb` | 512 | 0–8388608 MiB; 0 表示不设大小上限 |
| `daemon.history.max_age_days` | 0 | 0–36500 天； 0 表示不按年龄清理 |
| `daemon.history.compression` | zstd | zstd / s2 / none |
| `daemon.history.compression_level` | fast | fast / balanced / best |
| `daemon.resource_sampling.interval_ms` | 500 | 100–60000 ms |
| `daemon.resource_sampling.max_samples` | 512 | 512–65536 |

## 颜色字段

`tui.theme` 下的 `primary`、`secondary`、`foreground`、`background`、`muted`、`success`、`warning`、`danger`、`info` 接受空字符串或 `"#RRGGBB"`。`border.panel/active/inactive/muted` 与 `surface.chrome_bg/status_bg/overlay_bg/toast_bg` 同样适用。

空颜色使用内置、宿主或派生值。`mode: system` 当前不等于自动 OS 明暗同步。`profile` 不触发多 profile 合并。剪贴板 `max_items` 不应作为自动擦除敏感内容的保证。

## 模板与动作显示

- `chrome.workspace_template`、`tab_template`、`tab_create_template`、`pane_title_template` 是单行显示模板。
- `chrome.pane_glyphs` 包含图标、动作周围装饰、owner 和裁切提示。部分装饰字段显式空字符串表示隐藏，与省略字段不同。
- `chrome.picker.endpoint_status` 为各设备状态设置 glyph / style。
- `footer.templates` 格式化 mode、key、action 与摘要；`footer.modes` 设置各模式 badge。
- `shortcuts.actions` 覆盖动作显示；声明任意 scene 则替换整套默认绑定。

完整[中文注释模板](https://github.com/anytty/anytty/blob/main/tui/docs/tui-v3.example.yaml)与[推荐配置](https://github.com/anytty/anytty/blob/main/tui/docs/tui-v3.recommended.yaml)给出变量、样式 span 和动作格式。模板并不保存终端或布局状态。
